# content-hub · 口播内容中台

> 家庭教育 · 个人成长 · 自我成长｜口播选题与稿件库

这是我的内容生产工作台：**一条 Issue = 一个选题**，Markdown 存成稿，版本历史留痕。
把成长的过程公开出来，本身就是一种成长。

## 这个仓库怎么用

> **一页纸速查**：跟我说话的口令、怎么查看／添加素材、写稿前必看的几条 → [`GUIDE.md`](GUIDE.md)
> **待写清单**：接下来能直接动笔的 5 条，含来源、口令与写前注意 → [`notes/待写清单.md`](notes/待写清单.md)
> **已发布留档**：30 天打卡 8 期正文与配套物料逐字归档 → [`published/README.md`](published/README.md)

1. **有新想法** → 开一条 Issue，写清核心观点、目标人群、开头钩子；顺手分类存放：
   - 可写进口播的观点／感悟／经历碎片 → `materials/`
   - 运营经验、平台规律、判断取舍 → `notes/`（**不是口播素材，不照抄**）
2. **动笔写稿** → 先按 `templates/voice-and-structure.md`（**默认风格规范**：说话方式／格式／7 段结构／句式库／自检清单）写，成稿放 `scripts/年/月/`。只有要「教方法、列清单」时才用六段式备用模板 `templates/script-template.md`。写稿前后可读 `notes/operation-experience.md` 做判断参考（**运营经验沉淀，不是口播素材，不照抄**）
3. **录制发布** → 稿子定稿、录完、发出后，更新 Issue 上的状态标签
4. **复盘沉淀** → 表现好的钩子和金句，回填进 `insights/hooks.md`
5. **发布后归档** → 已发出的正文逐字存进 `published/`（不改、不润色，只补备注），顺手把 Issue 状态推进到 `已发布`

## 目录结构

| 目录 | 放什么 |
|---|---|
| `templates/` | **默认风格规范** `voice-and-structure.md`、六段式备用模板、选题卡模板 |
| `scripts/年/月/` | 成稿归档，文件名 `MMDD-主题.md` |
| `insights/` | 钩子与金句库，发布后回填 |
| `materials/` | 口播素材：观点、感悟、经历碎片，原话留存并标来源与关联 Issue，写稿时取用 |
| `notes/` | 运营经验、平台认知、账号定位与拍前要求，以及**待写清单**（`待写清单.md`，工作台排期索引）：写稿时的判断参考，**不是口播素材**，不产出可念的句子 |
| `published/` | **已发布成稿**，正文逐字留档＋配套物料；与 `scripts/` 的待定稿分开，只增不改 |

## 标签体系

**领域**：`家庭教育` · `个人成长` · `自我成长`

**状态**：`待写稿` → `写作中` → `待录制` → `已发布`

**形式**：`短视频` · `长内容` · `直播`

一条选题至少打两个标签：一个领域 + 一个状态。「当前所有未完成选题」= 开放 Issue 列表。
