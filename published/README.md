## 一、这个目录和 `scripts/` 有什么区别

| | `published/`（本目录） | `scripts/年/月/` |

| 是什么 | **已经发出去的内容**，事实留档 | 待写／写作中／待录制的**成稿**，还在改 |

## 四、⚠️ 三处引用合规风险（复用前必看）

发布版里有三处把书里的话写成了「原话／里那句」，但**都没跟纸质书逐字核对、没有章页**：

1. `day04`：「《家庭的觉醒》里面的这句话……**原话是**：孩子并不会过多的关注我们的出发点，而是关注我们反应给他们带来的感受。」
2. `day06`：「《家庭的觉醒》里那句：**觉醒的教养方式打破了传统的游戏规则，要改变的不是孩子，而是我们自身**。」（原文末尾还留着「（附带页码？」这个没解决的疑问）
3. `day08`：开篇「真正的贫穷不是物质匮乏，而是你的选择题里根本就没有其他选项」——未点书名，属于「听到的一句话」，风险较小；仓库内部存档记出处为《价值心法》P54（用户口述页码，未核对）。

**以后复用的统一写法**：「让我想到了《家庭的觉醒》当中的一个理念」——`想到了／理念` 是主观转述框架，不称原话、不用引用块、不报章页。要逐字引用，先拍正文页核对并标章页。仓库里**目前唯一逐字核对过的是 p.71 第 6 章两句**，见 `scripts/2026/11/1111-吓唬是向孩子借债.md` 内部存档。
